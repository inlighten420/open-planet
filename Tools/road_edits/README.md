# Road edits: how roads really are

Edits drawn in the game's road editor (F2, "fix the world"), kept as reference cases. They are guidelines drawn by hand,
not survey lines, and the game never loads them: the generator's rules are tuned until the roads it makes come out close
to them, everywhere like them (alongside the LiDAR truth test, Tools/truth_areas.ps1).

One file per place: the edit text as the editor copies it, with a line on what it shows.
